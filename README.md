# 毎日日記

シンプルで美しい日記アプリケーション

## 機能

- **日記の作成**: 日付を選択して、その日の出来事を記録できます
- **日記の保存**: ブラウザのローカルストレージに自動的に保存されます
- **日記の閲覧**: 過去の日記を時系列で表示します
- **日記の削除**: 不要な日記を削除できます

## 使い方

1. `index.html`をブラウザで開きます
2. 日付を選択して、内容を入力します
3. 「保存」ボタンをクリックするか、Ctrl+Enterキーで保存します
4. 過去の日記は下部に表示されます
5. 日記を削除したい場合は「削除」ボタンをクリックします

## 技術

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API

## インストール

特別なインストール手順は不要です。`index.html`をブラウザで開くだけで使用できます。

## ブラウザ対応

- Chrome/Chromium
- Firefox
- Safari
- Edge
